# 拖拉机（80 分 / 升级）

网页 3D 纸牌，你和对家徐涌一队，对阵两位电脑玩家。只用 HTML、CSS、JavaScript，没有第三方库，也没有图片和音频文件。

## 怎么玩

- **电脑上**：直接双击 `index.html`。
- **手机上**：和电脑连同一个 Wi-Fi，在这个文件夹里运行 `py -3 -m http.server 8001`，手机打开 `http://电脑的IP:8001`。手机竖着拿时会提示横过来。
- 发牌途中，你一有亮主或反主的机会，发牌就停下来等你选（亮，或者「不亮，继续发牌」），并轻轻提示一声。按过「不亮」的，按钮仍然留着，之后想亮随时点。点牌选中，按住滑动可以连选，再按「出牌」。「提示」按钮用电脑的逻辑帮你选牌（它也只看你的牌）。

规则在游戏里的「规则」按钮，写的就是程序实际执行的规则。各地打法有出入，数值在 `js/rules.js`。

## 公平性

- 洗牌用 `crypto.getRandomValues` 加 Fisher-Yates，没有取模偏差。
- 牌堆和手牌放在 `js/game.js` 的真私有字段（`#`）里，外部代码读不到。牌的编号就是在牌堆中的位置。
- 电脑只拿到 `view`：自己的手牌和出过的牌。底牌只有埋牌的庄家知道。
- 甩牌成不成由裁判核对，电脑领牌前并不知道别人有什么。
- 和对家的配合只靠看得见的出牌，没有通气。
- 电脑推演时只把自己没见过的牌随机分给别人，随机种子由 `view` 决定，同样的局面得到同样的决定。
- `tests/run_tests.js` 验证以上几点，并统计发牌分布。

## 电脑怎么打

`js/ai.js` 分两层：

1. **启发式评分**：领牌看哪些牌外面压不住、对手和对家断了哪门；跟牌看这一墩值多少分、对家守不守得住、要付出多少好牌。
2. **抽样推演**：候选不止一个时，取评分前 6 名，抽样 32 种「别人可能的手牌」，每个候选往后打 6 墩，再把推演结果和第一层的评分合起来比较。
3. **末家规则**：最后一家出牌时这一墩已经看得见，先去掉明显错的选择，比如对家已赢还用大牌去压。

这几层比调参有效得多，对打结果见 `docs/selfplay_log.md`。

推演分成很多小段，每算 8 ms 就让出一帧，所以电脑思考时动画不会卡，慢手机上也一样。

## 文件

| 路径 | 内容 |
|---|---|
| `js/cards.js` | 牌张、洗牌 |
| `js/rules.js` | 牌序、牌型、跟牌、比大小、算分（纯函数） |
| `js/game.js` | 裁判：一局的流程和信息隔离 |
| `js/ai.js` | 电脑玩家 |
| `js/art.js` `gfx.js` `scene.js` | 牌面绘制、WebGL2 渲染、牌桌布局和动画 |
| `js/app.js` | 界面 |
| `tools/selfplay.js` | 四人自我博弈：`stats`、`duel`、`sweep`、`tune` |
| `tools/snapshot.js` `tools/baselines/` | 保存和对打用的 AI 基线 |
| `docs/selfplay_log.md` | 每轮调参和逻辑改动的对打结果，包括没用的 |
| `docs/test_report.md` | 300 局实战测试报告 |
| `tests/run_tests.js` | 规则和公平性测试：`node tests/run_tests.js 800` |
| `tests/browser_check.mjs` | 无头 Edge 真实打一局并截图：`node tests/browser_check.mjs 目录 844 390 4 1 touch` |
| `tests/soak.mjs` | 在真实界面连打多局，查错误、卡顿、内存、布局：`node tests/soak.mjs 目录 --hands 300 --par 3 --speed 10 --w 844 --h 390 --dpr 2 --gl gpu --stall 400`，结果在目录里的 `report.json` |
| `tests/robot.mjs` | 给 `soak.mjs` 用的「真人」：加 `--human 1` 后不再由电脑代打你的座位，而是用真实的鼠标或触摸事件来打，包括手动选牌、滑动连选、故意出不合规的牌，同时乱点、连点、转屏、切后台、丢失 WebGL 上下文。`--sizes 844x390x2,667x375x2,1600x900x1` 让各个页面用不同屏幕 |
| `tests/audit.js` | 逐局查电脑的失误：`node tests/audit.js 300` |
