# 上海麻将（清混碰）

网页 3D 麻将，你对三位电脑玩家。只用 HTML、CSS、JavaScript，没有第三方库，也没有图片和音频文件（牌面、声音都是现场生成的，语音是浏览器自带的朗读）。

## 怎么玩

- **电脑上**：直接双击 `index.html`。
- **手机上**：打开网址后点「全屏开玩」，游戏只在全屏横屏下进行；竖着拿手机也会按横屏显示，不用转手机。iPhone 的 Safari 不能全屏，要先「分享 → 添加到主屏幕」，再从主屏幕的图标打开；微信里要先「在浏览器打开」。
- 鼠标：移到牌上抬起并显示「打这张听什么」，点一下打出。触屏：点一下抬起，再点一下打出。
- 总输赢：每局的输赢累计起来，写在各家名牌上名字的后面，结果里也列出。存在浏览器的 `localStorage`（`mj.totals.v1`；`?auto=1` 电脑代打时用 `mj.totals.auto.v1`）里，关掉网页、换游戏回来都接着算；开始画面列出各家的总输赢，下面是「所有玩家积分清零」：按一下变成「再按一次确认清零」，四秒内再按一下（隔半秒以上）四家都从 0、第 1 局重新算，别的存着的东西不动。
- 语音：吃、碰、杠、暗杠、加杠、补花、三口、开宝、自摸、胡了、拉杠胡、七捉一、八花、天胡、地胡、流局，哪一家做的就用哪一家的声音报；「过」「抓牌」只报你自己点的（电脑放过一张牌不出声，免得泄露它手里有能吃碰的牌）。摸牌、打牌不报；本游戏不报听。跟着「声音」的开关。

规则在游戏里的「规则」按钮，写的就是程序实际执行的规则。上海麻将各家打法有出入，数值都集中在 `js/rules.js` 开头的 `VALUES`，可以按自己的习惯改。

## 语音

用浏览器自带的朗读（Web Speech API），没有音频文件，网页自己不向任何服务器要声音（浏览器里「联网」的声音由浏览器去取）。每次说话时从浏览器有的声音里挑：上海话（吴语，语言代码 `wuu`）→ 普通话 → 别的中文（台湾国语、东北话等）→ 粤语；一个中文声音都没有就不说，别的照旧。同一类里本机的在前（快，断网也能用）、男声在前，四家各用一个，不够四个就用音高和语速分开。联网的声音连着两次出不来，一分钟内改用本机的。

**上海话要看设备有没有这个声音**：有语言代码是 `wuu` 的声音就会自动用上；没有的设备说普通话。电脑上的 Edge（2026-11 看过，325 个声音）没有吴语，用云希、云健、云扬、云夏这几个普通话声音。

说什么都在 `js/voice.js` 开头的 `PHRASES` 一张表里。牌局从不等语音：正在说的一句让它念完，排队的只留最新一句，等了一秒半以上的不再说（胡牌、流局除外）。手机浏览器要先点一下才肯出声，所以点「开始」时先说一句空话（听不见）。

## 公平性

- 洗牌用 `crypto.getRandomValues` 加 Fisher-Yates，没有取模偏差。
- 牌墙和手牌放在 `js/game.js` 的真私有字段（`#`）里，外部代码读不到。牌的编号就是在牌墙中的位置，不透露牌种。
- 电脑只拿到 `view`：自己的手牌和桌面公开信息。别人的暗杠看不到牌种。
- 电脑的决定是 `view` 的纯函数，不用随机数；响应打牌时各家互不知情，也不加「想一下」的延迟。
- `tests/run_tests.js` 验证以上几点，并统计发牌分布和座位胜率。

## 文件

| 路径 | 内容 |
|---|---|
| `js/tiles.js` | 牌张、洗牌 |
| `js/rules.js` | 牌型判定、算花、算点、结算（纯函数） |
| `js/game.js` | 裁判：一局的流程和信息隔离 |
| `js/ai.js` | 电脑玩家，原理和参数见 `docs/ai.md` |
| `js/art.js` `gfx.js` `scene.js` | 牌面绘制、WebGL2 渲染、牌桌布局和动画 |
| `js/voice.js` | 语音：每个操作说什么、用哪个声音、排队 |
| `js/app.js` | 界面：事件变动画，点击变动作 |
| `tools/selfplay.js` | 四家自我博弈：统计、同牌对打、调参 |
| `tools/snapshot.js` `tools/baselines/` | 保存和对打用的 AI 基线 |
| `tools/danger_stats.js` | 从对局统计真实放炮率：`node tools/danger_stats.js 8000` |
| `docs/selfplay_log.md` | 每轮调参和逻辑改动的对打结果，包括被否决的 |
| `docs/test_report.md` | 300 局实战测试报告 |
| `tests/run_tests.js` | 规则、公平性和语音的测试：`node tests/run_tests.js 2000` |
| `tests/browser_check.mjs` | 无头 Edge 真实打一局并截图：`node tests/browser_check.mjs 目录 844 390 4 1 play touch` |
| `tests/voice_check.mjs` | 无头 Edge 里查语音和开始画面的清零：假的朗读记下说了什么，和牌局记录一句一句地对；手机竖拿、横拿和电脑的大小都查：`node tests/voice_check.mjs 目录 --hands 4`（`--only play`、`--base 网址` 见文件开头） |
| `tests/soak.mjs` | 在真实界面连打多局，查错误、卡顿、内存、布局、总输赢是否等于各局输赢之和：`node tests/soak.mjs 目录 --hands 300 --par 3 --speed 10 --w 844 --h 390 --dpr 2 --gl gpu --stall 400`，结果在目录里的 `report.json` |
| `tests/robot.mjs` | 给 `soak.mjs` 用的「真人」：加 `--human 1` 后不再由电脑代打你的座位，而是用真实的鼠标或触摸事件来打，同时乱点、连点、转屏、切后台、丢失 WebGL 上下文。`--sizes 844x390x2,667x375x2,1600x900x1` 让各个页面用不同屏幕 |
| `tests/audit.js` | 逐局查电脑的失误：`node tests/audit.js 300` |
