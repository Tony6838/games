怎么用

  • 选话题：点上面的话题（手机上：标题「瑞典语读报」旁边的下拉菜单），下面列出这个话题今天的几篇新闻（今天还没有的，列最近的），点一篇来读。再点一次同一个话题，换一批，列过的不会再列（手机上：点列表最下面的「换一批」，或者播放栏最右边的 → 按钮）。读完点「← 返回列表」回到列表，或者点播放栏最右边的 → 按钮（下一篇）读列表里的下一篇。
  • 朗读：点话题按钮后面那组立体按钮里蓝色的 ▶ 按钮（手机上在标题下面一行，往下滚时一直在顶上）。这组按钮只有图标：鼠标停在按钮上（手机上按住半秒）显示它是做什么的。正在读的单词下面有一条下划线，跟着往下走。切到别的标签页、窗口最小化、手机锁屏时接着读（锁屏后继续朗读需要云端语音，手机上设备自己的声音锁屏就停，回来接着读）；手机锁屏界面、电脑键盘的媒体键可以暂停、继续、下一篇。
  • 暂停：按空格，或者点一下文章。再按空格或点 ▶，从停下的地方接着读。
  • 语速：▶ 后面的按钮（上面写着 0.9× 之类），点一下换一档：0.8× → 0.9× → 1× → 循序渐进三连读 → 0.8×。三连读：一篇读三遍，第 1 遍 0.8× 慢读，便于理解；第 2 遍 0.9×，便于练习；第 3 遍 1×，正常速度；每遍之间停一下，从头再读。按钮上有三级台阶，亮到第几级就是第几遍。读的时候点它马上换语速；暂停、继续还在这一遍里；打开别的文章、下一篇从第 1 遍开始。
  • 读完以后：「女 / 男」后面那个重复图标的按钮，点一下换一种：读完就停（灰色的重复图标）→ 接着读下一篇（几行字和一个播放三角）→ 本篇循环（重复图标里有个 1）。接着读下一篇：读完停一下，自动打开列表里的下一篇接着读，这一批读完了就取下一批；本篇循环：读完从头再读，一遍又一遍，直到按暂停。用三连读时，三遍都读完才按这里的来（接着读下一篇也是三遍，本篇循环是三遍再来一次）。停一下的时候按暂停，就不接着读了。锁屏时也接着读（要云端语音）。这台设备的浏览器会记住。
  • 查词：鼠标停在词上，或者点一下词，就显示中文。一个词有几个意思时，全都列出来，下面自动显示这一整句的译文；能确定这句里是哪个意思时，那个意思和整句译文里它的译文下面各有一条蓝色下划线，拿不准就不画，对着整句看就知道。喇叭读这个词，「从这里读」从这个词开始朗读，「本句译文」翻译这一整句。电脑上用鼠标选中几个词，也会翻译选中的部分。
  • 整篇翻译：用浏览器自带的整页翻译。别的浏览器：Safari、iPhone、iPad 点地址栏「aA → 翻译成中文」；安卓的 Chrome 点右上角 ⋮ →「翻译…」；Firefox 用地址栏的翻译图标。
  • 在线翻译：查词和「本句译文」用微软翻译（微软不保存文字）。它的免费额度大家共用，用完时自动改用浏览器内置的翻译（Chrome、Edge 电脑版），没有内置翻译时，点词、点「本句译文」用 MyMemory 在线翻译（鼠标只是停在词上时不用；默认开着；它会保存收到的句子，不想用可以在顶部齿轮按钮「设置」里关掉）。
  • 简易瑞典语：最后一个话题，是 SR 专门用简单的瑞典语写的新闻；别的话题都是普通的瑞典新闻。
  • 声音：点「女 / 男」按钮切换女声、男声；在「设置」里可以选具体的声音和语速。默认用云端自然语音（微软的 Sofie、Hillevi 女声，Mattias 男声），电脑、手机、任何浏览器上都一样，要联网；云端不通时自动改用设备自带的声音（Edge 浏览器有微软的 Sofie、Mattias，苹果设备有 Alva、Klara、Oskar）。在「设置」里也可以自己选用设备的声音。
  • 字号：右上角的 A− 和 A+。
  • 按钮的瑞典文：鼠标停在任何一个按钮上（手机上按住按钮半秒），显示这个按钮的瑞典文说法和中文说明，顺便学几个词；播放栏上只有图标的按钮，也这样看它是做什么的。手机上按住看提示，松手不算点了按钮。
