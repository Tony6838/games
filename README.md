# 上海麻将 · 拖拉机

两个网页 3D 单机牌类游戏：你对三位电脑玩家。打开就能玩，不用登录，没有广告，电脑和手机横屏都可以。

- **在线玩**：<https://tony6838.github.io/games/>
- **上海麻将（清混碰）**：<https://tony6838.github.io/games/MaJiang/>
- **拖拉机（80 分）**：<https://tony6838.github.io/games/Tractor/>
- **瑞典语读报**（给学瑞典语的中文读者）：<https://tony6838.github.io/games/Svenska/> —— 按话题读今天的瑞典新闻（瑞典广播电台的普通新闻），朗读并高亮正在读的词，点词看中文和听发音，可以把全文翻译成中文。

这是沈强孝敬母亲胡杏素开发的免费无广告无作弊无偷看版本的网络版单机游戏。
老母中风之后唯一的娱乐活动就是打牌和麻将，但是无良奸商把这些游戏变成需要登陆购买金币才能玩的真正的昂贵的赌博。
欢迎传播和免费使用，作者对游戏的安全负责。
改进意见可以发电子邮件给作者 Tony.Shen.Qiang@Gmail.Com

## 特点

- 只用 HTML、CSS、JavaScript，没有第三方库，也没有图片和音频文件：牌面、牌桌、声音都是程序现场生成的。
- 洗牌用浏览器的密码学随机数，发牌完全随机。
- 电脑玩家只知道自己的牌和桌面上看得见的牌，不会偷看，也没有特殊待遇。它们都在尽力赢、争取最大的赢点。
- 规则写在游戏里的「规则」按钮下，写的就是程序实际执行的规则。

## 在自己电脑上玩

下载或克隆这个仓库，双击 `MaJiang/index.html` 或 `Tractor/index.html` 即可，不需要安装任何东西。

## 手机上

点「全屏开玩」后游戏在全屏横屏下进行，竖着拿手机也按横屏显示。iPhone 的 Safari 不允许网页全屏：请点「分享 → 添加到主屏幕」，以后从主屏幕的图标打开。在微信里打开的，请先点右上角「…」选「在浏览器打开」。
